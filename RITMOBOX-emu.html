Clique n’importe où pour activer l’audio.

Glisser verticalement sur un potard (ou molette) ; double-clic = réglage médian. SOUND SEL. : 1×–5× = CH, OH, G1, G2, G3 · 6× = TAP (pas 1-5 jouent les sons) · 7× = MUTE. LOAD/SAVE puis un pas (9-16 pour les slots 9-16). LOAD puis SAVE = efface le son courant ; SAVE puis LOAD = efface tout. Entrée MIDI : notes 48, 50, 52, 53, 55 · Start/Stop.
